🔧 Google OAuth 2.0 Setup Guide

⚠️ Important: Make sure you're logged into the Google account that owns the OAuth Client ID: 371357217343-ihm24nevjs05qijuebtrc7vdv33cpuuj.apps.googleusercontent.com
1

Go to Google Cloud Console

Open Google Cloud Console

Make sure you select the correct project that contains your OAuth Client ID.

2

Find Your OAuth 2.0 Client ID

Look for the section labeled "OAuth 2.0 Client IDs" (not "API Keys").

You should see your client ID: 371357217343-ihm24nevjs05qijuebtrc7vdv33cpuuj.apps.googleusercontent.com

💡 If you don't see any OAuth 2.0 Client IDs, you may need to switch to the correct project or create a new one.
3

Click on the Client ID Name

Click on the name of your OAuth client (it might show as something like "Web client" or your project name).

Don't click on the download icon - click on the text/name itself.

4

Find "Authorized redirect URIs"

In the settings screen that opens, scroll down until you see a section called:

→ "Authorized redirect URIs"

This section contains a list of URLs where Google is allowed to redirect after authentication.

5

Add Your Redirect URI

Click "ADD URI" or "+ ADD URI"

Enter exactly:

http://localhost:1420/test-oauth.html

Then click "Save" or "Update"

⚡ You can also add these for testing:
http://localhost:1420/simple.html
http://localhost:1420/demo.html
6

Wait for Changes to Propagate

Google's OAuth changes can take a few minutes to take effect.

Wait 2-5 minutes, then try the OAuth test again.

✅ Once configured:

1. Go back to http://localhost:1420/test-oauth.html

2. Click "Test Basic Google OAuth"

3. You should be redirected to Google's login screen

4. After signing in, you'll be redirected back with an authorization code

🚨 Troubleshooting:
• If you still get 404 errors, double-check that you added http://localhost:1420/test-oauth.html exactly (no trailing slash)
• Make sure you're editing the correct OAuth 2.0 Client ID (not an API Key)
• Check that you're logged into the correct Google account
