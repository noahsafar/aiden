This edit explicitly defines invitations with registration deadlines/RSVPs as distinct scheduled occurrences, ensuring correct classification of events like "Leadership Workshop" or "Conference Early Bird".

"event" if it's a talk, seminar, workshop, webinar, lecture, presentation, panel, networking event, office hours, or any distinct scheduled event the user is invited to attend.
  * EXCLUSION: Do NOT set is_meeting=true for newsletters or marketing emails that merely MENTION events (e.g. "WWDC is June 10") without inviting the user.

Function: analyze_email_claude
Dimension(s): deadline_detection
Reasoning: The system misses valid deadlines in transactional emails (e.g., invoices, subscription renewals) because the current prompt language implies a "question" or "personal action" is needed.   * Use ISO format (YYYY-MM-DD). Set to null if no deadline applies.
